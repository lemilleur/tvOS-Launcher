# Документация tvOS Launcher

tvOS Launcher заменяет главный экран Android TV и Google TV. Здесь собраны инструкции для пользователей и разработчиков русскоязычного форка.

- [Установка и обновление](install.md) — готовый APK, установка через ADB и разрешения.
- [Возможности](features.md) — главный экран, погода, онлайн-обои, поиск, управление с пульта и профили.
- [Презентация](presentation.md) — загрузка материалов из браузера, показ на ТВ и веб-API.
- [Сборка и запуск](getting-started.md) — Android SDK, PowerShell, Bash и эмулятор.
- [Архитектура](architecture.md) — компоненты лаунчера и особенности отрисовки.
- [Как внести изменения](../CONTRIBUTING.md) — правила работы с кодом и проверка на телевизоре.
