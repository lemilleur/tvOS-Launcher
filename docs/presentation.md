# Режим презентации

Презентация превращает телевизор в экран для циклического показа изображений, видео и веб-страниц. Управление доступно из браузера на телефоне или компьютере в одной локальной сети с телевизором. Режим основан на PB Marketer TV и использует шестизначный код сопряжения.

## Включение

Откройте настройки презентации в лаунчере.

| Параметр | Действие |
|---|---|
| Режим презентации | Запускает локальный веб-сервер на порту 8080 и добавляет плитку «Презентация» |
| Запуск при включении ТВ | Открывает презентацию после загрузки устройства |
| Не выключать экран | Удерживает экран включённым во время показа |
| Адрес и код сопряжения | Показывает адрес сервера, QR-код и код |
| Запустить сейчас | Открывает полноэкранный показ |

При начале показа адрес и QR-код на несколько секунд появляются на телевизоре.

## Загрузка и плейлист

1. Откройте адрес с экрана телевизора, например `http://192.168.1.13:8080`, или отсканируйте QR-код.
2. Введите шестизначный код. После перезапуска ТВ код меняется.
3. В библиотеке перетащите фотографии и видео в область загрузки. Файлы можно фильтровать и удалять.
4. Добавьте слайд из библиотеки или укажите адрес веб-страницы. Порядок меняется перетаскиванием миниатюр или кнопками перемещения.
5. Настройте время показа и способ вписывания слайда. Для видео можно включить звук, для страниц — прокрутку и паузу между её шагами.
6. Нажмите «Сохранить на ТВ». С панели воспроизведения можно переключить слайд, поставить показ на паузу, начать сначала или показать код сопряжения.

## Управление с пульта

| Кнопка | Действие |
|---|---|
| ◀ / ▶ | Предыдущий или следующий слайд |
| OK | Пауза или воспроизведение |
| ▲ / ▼ / Info | Показать адрес, QR-код и код сопряжения |
| Два нажатия «Назад» | Выйти на главный экран |

Изображение показывается заданное время, по умолчанию 10 секунд. Видео воспроизводится до конца и по умолчанию выключает звук. Веб-страницы открываются с областью просмотра шириной 1920 пикселей. При включённой прокрутке слайд завершается после просмотра страницы, иначе применяется заданное время показа, по умолчанию 20 секунд. Слайд с ошибкой пропускается после короткого сообщения. Если плейлист пуст, на ТВ отображаются данные для сопряжения.

## Веб-API

Вызовы, кроме `/api/info` и `/api/pair`, требуют `Authorization: Bearer <token>`. Для URL медиафайлов можно передать `?token=`. Формат данных — JSON, а загрузка файлов поддерживает отдельные форматы.

| Метод и путь | Назначение |
|---|---|
| `GET /api/info` | Название, устройство, порт, адреса, версия и `pairingRequired` |
| `POST /api/pair` с `{pin}` | Обмен шестизначного кода на `{token}` |
| `GET /api/media` | Список `{media: [...]}`, новые файлы первыми |
| `POST /api/media` | Загрузка через multipart-поле `file` с необязательными `mimeType` и `originalName` либо через тело с `X-File-Name` и `X-File-Type` |
| `GET /api/media/{id}/file` | Получение файла |
| `DELETE /api/media/{id}` | Удаление файла и использующих его слайдов |
| `GET /api/playlist` | Текущий плейлист `{playlist}` |
| `PUT /api/playlist` с `{name, slides}` | Замена плейлиста с проверкой данных |
| `GET /api/playback/status` | Состояние воспроизведения и текущий слайд |
| `POST /api/playback/control` с `{command}` | `play`, `pause`, `next`, `previous`, `restart`, `showConnectionInfo` |

Для совместимости сохранены `GET/POST /api/playlists`, `GET/PUT /api/playlists/{id}` и `POST /api/playlists/{id}/activate`.

Поля слайда: `id`, `type` (`image`, `video` или `webpage`), `durationSec`, `mediaId`, `url`, `fitMode` (`contain`, `cover` или `fill`), `muted`, `loop`, `webpageAutoScroll`, `webpageScrollSpeedPxPerSec` (5–1000), `webpageScrollPauseSec` (0–300), `enabled` и `order`.

## Хранение

Плейлист и метаданные хранятся в `signage.db`, в таблицах `media` и `playlists`. Загруженные файлы лежат в каталоге приложения `files/media/`. Сервер пишет поток на диск во время загрузки.
