# Архитектура

## Сборка

Сценарии `build.ps1` и `build.sh` последовательно запускают `aapt2`, `javac --release 11` с Android SDK 34, `d8` для API 24+, `zipalign` и `apksigner`. Ресурсы интерфейса, шрифт Inter и веб-интерфейс презентации входят в APK. Реализация QR-кодов Nayuki включена исходным кодом под лицензией MIT. [Инструменты и команды](getting-started.md)

Основной Java-код находится в `src/com/techgenius/tvoslauncher/`.

## Отрисовка и данные

- Размеры рассчитываются относительно сетки 960×540. Интерфейс сохраняет пропорции при выводе на 720p, 1080p и 4K.
- Для Liquid Glass лаунчер готовит размытую копию фона при его смене. Стеклянные панели используют участок этого изображения, совпадающий с их положением на экране.
- Сетевые запросы, чтение изображений и подготовка тяжёлых фоновых слоёв выполняются в фоновых потоках. Кэш погоды общий для разных экранов. Временные метки хранятся отдельно от подписей в часовом поясе города.
- Поиск приложений работает по списку в памяти. Запрос фильмов отправляется после паузы при вводе. Обложки декодируются в нужном размере и хранятся в ограниченном кэше.
- Для «Продолжить просмотр» используется доступная устройству информация Watch Next и медиасеансов. Для поиска и рекомендаций используются отдельные источники каталога.

## Проверка производительности

Статистику отрисовки можно получить командой `adb shell dumpsys gfxinfo com.techgenius.tvoslauncher.fork`. Сравнивайте плавность дока и полноэкранных переходов на реальном устройстве. Эмулятор подходит для проверки раскладки и навигации.
