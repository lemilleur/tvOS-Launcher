# Установка и обновление

Нужны Android TV или Google TV с Android 7.0 и новее. Готовый `tvos-home.apk` доступен в [релизах русскоязычного форка](https://github.com/lemilleur/tvOS-Launcher/releases/latest).

## Установка через ADB

1. Установите Android SDK Platform Tools на компьютер.
2. В настройках телевизора откройте сведения об устройстве и нажмите семь раз на строку «Сборка». Затем в параметрах разработчика включите отладку, которую поддерживает телевизор.
3. Подключите компьютер и ТВ к одной сети. Замените IP в примере на адрес телевизора и подтвердите подключение на его экране.

```sh
adb connect 192.168.1.13:5555
adb -s 192.168.1.13:5555 install -r tvos-home.apk
adb -s 192.168.1.13:5555 shell am start -n com.techgenius.tvoslauncher.fork/com.techgenius.tvoslauncher.MainActivity
```

Флаг `-r` обновляет установленное приложение с сохранением настроек при совпадении пакета и подписи. APK этого форка использует пакет `com.techgenius.tvoslauncher.fork`. Если Android сообщает `INSTALL_FAILED_UPDATE_INCOMPATIBLE`, нужна сборка с ключом текущей установки. Удаление приложения очищает его настройки.

После первого запуска пройдите мастер. Чтобы открывать лаунчер кнопкой Home, выберите его в настройках главного экрана Android или воспользуйтесь соответствующим пунктом мастера. Доступность системного выбора зависит от прошивки.

## Разрешения

Предпочтительный способ — экран разрешений в мастере первого запуска или в настройках лаунчера.

| Возможность | Что нужно включить |
|---|---|
| Название сети Wi‑Fi | Доступ к местоположению в системном запросе |
| «Продолжить просмотр» и «Не беспокоить» | Доступ к уведомлениям |
| Таймер сна и выключение экрана | Администратор устройства либо служба специальных возможностей, в зависимости от прошивки |
| Действия кнопок пульта | Служба специальных возможностей лаунчера |
| Голосовой поиск | Доступ к микрофону или системный голосовой ввод |

## Дополнительные источники

Для рекомендаций в верхней полке доступны JustWatch, Stremio и TMDB. Для TMDB укажите свой ключ в настройках. Stremio открывает выбранный фильм или сериал в Stremio либо Nuvio, если установлен только Nuvio.

## AirPlay

Для приёма трансляций установите [AirPlay Server](https://github.com/jqssun/android-airplay-server), задайте имя телевизора в приложении и включите запуск при включении ТВ. Телевизор и устройство Apple должны находиться в одной сети. Фоновая проверка лаунчера помогает приёмнику снова объявить себя в сети после сна.

## Возврат к системному лаунчеру

Выберите стандартный главный экран в настройках Android. Если системный лаунчер был отключён, сначала включите его в разделе приложений. Удалить форк можно из меню приложений или командой:

```sh
adb uninstall com.techgenius.tvoslauncher.fork
```
