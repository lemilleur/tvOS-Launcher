# Как внести изменения

Начните с [руководства по сборке](docs/getting-started.md) и [карты исходников](docs/architecture.md). Для вклада в проект создайте отдельную ветку и откройте pull request в `main`. Опишите, что изменилось, зачем и на каких устройствах это проверено.

## Код и интерфейс

- Проект использует Java 11 на уровне исходников, JDK 17+ для сборки и Android API 24+ для запуска. Вызовы новых Android API должны проверять версию платформы.
- Повторно используйте компоненты проекта. Экраны и элементы интерфейса создаются в Java. Для размеров и текста используйте `Ui.px`, `dp` и `Ui.textSize`.
- Пользовательские строки добавляйте через существующий механизм локализации. Храните исходники в UTF-8.
- Сеть, чтение файлов и декодирование изображений выполняйте вне потока интерфейса.
- При изменении интерфейса проверьте управление стрелками, OK, «Назад» и Home. Фокус должен оставаться видимым и доступным с пульта.
- Для сторонних материалов сохраните сведения об авторе и лицензии. Токены, пароли и закрытые ключи подписи храните вне репозитория.

## Проверка

1. Соберите APK и установите его на Android TV или эмулятор.
2. Пройдите изменённые сценарии с пульта. Для сетевых функций проверьте восстановление после сбоя.
3. Для визуальных изменений приложите скриншоты. На главном экране сравните плавность навигации до и после изменения.
4. Посмотрите ошибки через `adb logcat -s TvHome AndroidRuntime`.
5. Обновите документацию, если поменялись настройки, команды или поведение приложения.
