# tvOS Launcher

Русскоязычный лаунчер для Android TV и Google TV в стиле tvOS 26. Работает на Android 7.0 и новее. Собирается на Java с помощью Android SDK.

**[Скачать последнюю версию APK](https://github.com/lemilleur/tvOS-Launcher/releases/latest)** · **[Установка](docs/install.md)** · **[Документация](docs/README.md)**

## Возможности

- **Два режима главного экрана.** «Ночные сцены» с многослойными фонами, крупными часами и доком Liquid Glass. «Классический» с сеткой приложений, верхней полкой и настраиваемыми часами.
- **Погода для России.** Поиск города на русском или определение по IP. Виджет, ночные сцены и панель управления используют один прогноз с учётом часового пояса города. Основной источник — MET Norway, резервные — Open‑Meteo и wttr.in.
- **Обои.** Свои изображения, случайная смена из папки и бесплатные подборки Wikimedia Commons: космос, природа, города, животные и море. В меню онлайн-обоев можно выбрать интервал, перейти к следующему фону или переключиться на Reddit.
- **Виджеты.** Погода, футбольные матчи, популярные фильмы и сериалы, время молитв. Каждая карточка включается отдельно.
- **Приложения и профили.** До трёх профилей со своим порядком и скрытыми приложениями. Меню по удержанию OK позволяет перемещать и переименовывать приложения, менять их значки. «Продолжить просмотр» зависит от данных, которые предоставляет приложение.
- **Пульт и панель управления.** Настраиваемые действия для одного, двух и трёх нажатий, переключение HDMI, недавние приложения, таймер сна и быстрые настройки.
- **Режим презентации.** Загрузка фотографий, видео и веб-страниц из браузера по локальной сети с циклическим показом на телевизоре.
- **Обслуживание.** Резервное копирование настроек, CleanYourTV, настройка локального ADB и проверка обновлений на GitHub.

## Установка

Скачайте `tvos-home.apk` со страницы релиза. Можно открыть файл на телевизоре или установить его с компьютера через ADB:

```sh
adb connect <IP-телевизора>:5555
adb install -r tvos-home.apk
adb shell am start -n com.techgenius.tvoslauncher.fork/com.techgenius.tvoslauncher.MainActivity
```

APK релиза использует пакет `com.techgenius.tvoslauncher.fork`. Для обновления существующей установки Android проверяет, что подпись совпадает. Подробнее в [инструкции по установке](docs/install.md).

## Сборка из исходников

Нужны JDK 17+, Android SDK Platform 34 и Build Tools 34.0.0.

| Система | Команда |
|---|---|
| Windows | `.\build.ps1 -ForkPackage` |
| macOS и Linux | `./build.sh` |

Готовый файл — `build/tvos-home.apk`. Команда для Windows собирает пакет форка. Установка инструментов и параметры сборки описаны в [руководстве разработчика](docs/getting-started.md).
